# Adivasi Shiksha

**A student prototype for a simpler scholarship journey for tribal students.**

Built by **THE INFINITY SQUAD** for Smart India Hackathon 2026 · Problem Statement **SIH26238** · Team ID **179195**

🔗 **Live demo:** [the-infinity-squad-by-vsk.vercel.app](https://the-infinity-squad-by-vsk.vercel.app/)

## What we are exploring

Finding the right scholarship and understanding each application step can be difficult, especially when information, connectivity and support are limited. Adivasi Shiksha brings the student journey into one place: explore scheme examples, walk through a guided application, view a sample status journey, and see how student and officer workspaces could fit together.

The prototype is designed to be easy to try on a phone or computer. It includes English and Hindi interface options, additional Bodo and Santali options, browser-based read-aloud and voice controls where supported, and a cached app shell for repeat visits.

## Try the prototype

Open the live demo and start from a fresh session. You can explore the student portal, application steps, help view, status screen and officer dashboard. No account is needed.

The current demo keeps its sample activity in the open browser tab. Refreshing or closing the tab clears it. The application flow and officer actions are demonstrations; they do not submit an application to a scholarship authority.

## Current prototype status

This is an early front-end prototype. It demonstrates screens and sample journeys; it is not connected to government scholarship systems.

- **Available to explore:** responsive portal screens, sample scheme matcher, guided application UI, local document preview, sample status and grievance journeys, officer dashboard views, language selector and browser-dependent accessibility controls.
- **Not connected yet:** real student accounts, a server or database, official eligibility verification, document OCR or verification, Aadhaar/DigiLocker, scholarship submission, DBT/payment, SMS/WhatsApp notifications, or a live government grievance/appeal service.
- **Offline behaviour:** the app shell and listed assets can be cached by the browser. Form data is not saved for later or synchronised between devices.
- **Language and voice support:** availability depends on the current browser and device. Bodo and Santali options are prototype UI translations; full verified translations and speech support are future work.

## Privacy for demo users

This is a student project, not an official Government of India website or service. Please use fictional sample information only. Do not enter real Aadhaar, bank, date-of-birth, OTP or other personal details, and do not upload real documents.

## Run it locally

The prototype is a static site and needs no package installation.

1. Download or clone this repository.
2. Open `index.html` in a browser, or serve this folder with any static web server.

Keep `manifest.json`, `sw.js`, `chakra.svg`, `icon.svg`, `modi-portrait.png` and `tribal-students-hero.png` alongside `index.html` so the page and installable app shell can load their assets.
