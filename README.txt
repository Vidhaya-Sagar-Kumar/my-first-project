The preview starts empty and uses fictional demo data in the current browser tab only. Entries are not sent to a server and clear on refresh or leaving. The header mark is an original Ashoka Chakra-inspired 24-spoke wheel, not the State Emblem. The hero includes a portrait crop from the image supplied by the user, labelled as illustrative with no endorsement implied.

To preview locally: open index.html or run a static web server from this folder. For the free Vercel preview, use the folder upload option on vercel.com/new and set the project slug to the-infinity-squad-by-vsk if available. The project/team name displayed in the site remains THE INFINITY SQUAD.
